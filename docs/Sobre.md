# SISTEMA DE GERENCIAMENTO DO CAPS

## OBJETIVO
    Criar um sistema de controle de pacientes e serviços realizados 
    no CAPS, para facilitar o controle dos processos dentro do caps,tanto de pacientes como outros serviços

## PROBLEMAS IDENTIFICADOS
    - Processos manuais(Cadastro, pesquisa)
    - Lentidão nos processos que envolvem contabilizar pacientes
    
## PARTICIPANTES
    -> PACIENTE
    -> PROFISSIONAL
    -> MEDICAMENTO
    -> CONSULTA
    -> APLICAÇÃO
    -> ADMIN

## REQUISITOS FUNCIONAIS
    -> RF01 - CADASTRAR PACIENTE
    -> RF02 - REMOVER PACIENTE
    -> RF03 - ALTERAR PACIENTE
    -> RF04 - LISTAR PACIENTE(STATUS, IDADE, BAIRRO)

    -> RF05 - CADASTRAR PROFISSIONAL
    -> RF06 - REMOVER PROFISSIONAL
    -> RF07 - ALTERAR PROFISSIONAL
    -> RF08 - LISTAR PROFISSIONAL
    
    -> RF09 - CADASTRAR MEDICAMENTO
    -> RF10 - LISTAR MEDICAMENTOS
    -> RF11 - REMOVER MEDICAMENTO
    -> RF12 - ALTERAR MEDICAMENTO
    -> RF13 - ADICIONAR ESTOQUE

    -> RF14 - APLICAR MEDICAMENTO
    -> RF15 - LISTAR APLICAÇÃO

    -> RF17 - REALIZAR CONSULTA
    -> RF18 - LISTAR CONSULTA(DATA, PACIENTE, PROFISSIONAL)

    -> RF19 - CADASTRAR ADMIN
    -> RF20 - LISTAR ADMIN

    -> RF21 - EMITIR RELATÓRIO MENSAL

## REQUISITOS NÃO FUNCIONAIS
    -> RNF01 - O SISTEMA DEVE TER AUTENTICAÇÃO
    -> RNF02 - APENAS ALGUNS USUÁRIOS PODEM ACESSAR CERTAS FUNCIONALIDADES
    -> RNF03 - TODAS AS INFORMAÇÕES DE USUÁRIOS DEVEM SER PROTEGIDOS DE EXPOSIÇÃO 

## REGRAS DE NEGÓCIO
    -> RN01 - APENAS ADMIN PODE CADASTRAR ADMIN E PROFISSIONAL
    -> RN02 - O LOGIN DEVE SER ÚNICO
